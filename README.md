# 💖 Click Here to Show I Love You

An animated love note built with **Node.js (Express)**, **Tailwind CSS** and **GSAP**, plus a hand-written canvas particle engine.

## What happens

1. A glowing, heartbeating **"Click here"** button floats in a twinkling night sky, with ripple rings and a magnetic pull toward your cursor.
2. Click it and the button shatters into ~2,000 particles that swarm together into a **giant beating particle heart** (lub-dub rhythm, cursor repels the particles).
3. **"I Love You"** flips in letter by letter in 3D with a blur-to-sharp shimmer, while **heart-shaped fireworks** burst around it.
4. Tap anywhere for more heart fireworks, or hit **↺ Again** to replay.

## Run it

```bash
npm install
npm start
```

Then open http://localhost:3000. Use `npm run dev` to auto-restart the server on changes, and `npm run watch:css` to rebuild Tailwind as you edit.
